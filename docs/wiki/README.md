# KOLBB Wiki · 下班百科

> 今天的班，就上到这里。

KOLBB 是一款以 LBB 办公室为舞台的双人对抗像素格斗游戏。选择擅长远程控场的 **RajerWei**、近身压制的 **JU GUAI**，或篮球牵制与节奏突进的 **little black**，通过拳脚、方向指令、食物与 MAX 争取下班胜利。

本百科对应 **0.1.2 / rules-3（2026-09-11）**，涵盖 Godot 桌面端与微信小游戏。规则与数值核对自游戏代码；人物背景属于虚构游戏设定。攻略是依据机制给出的练习建议，不代表已验证的必胜打法。

本轮调整三角色的远程、食物、突进和 MAX 费用，两端采用相同战斗数值。互联网对战需要客户端与对应服务端使用相同的 rules-3 规则，详见[联机与版本兼容](online.md#version-compatibility)。本次部署更新百科；游戏客户端与服务端的升级另行进行。

## 本轮平衡调整

| 项目 | 当前规则 |
| --- | --- |
| RajerWei | 大便伤害 60、收招 18 帧；汉堡与肯德基挚友各耗 50，收招分别为 23／24 帧 |
| JU GUAI | 积分速度降为 4 像素／帧，寿命延至 150 帧，伤害仍为 60 |
| little black | 篮球伤害 50；铁山靠伤害 75、命中硬直 26 帧、收招 28 帧 |
| 三人 MAX | MAX 内超必杀本次消耗 100；普通 MAX 接大招总计 200，快速 MAX 接大招总计 300 |
| CPU | 修正蹲攻击输入与选择，使三角色的蹲招正常参与对战 |

独立验收共 **576 场**，覆盖三组角色对位、三档 CPU 和左右换边。RajerWei、JU GUAI、little black 的总胜率分别为 **46.4%／49.2%／54.4%**；微信构建所用引擎与桌面引擎的全部九组统计记录一致。

各对位中，RajerWei 对 JU GUAI 为 52.6%，RajerWei 对 little black 为 40.1%，JU GUAI 对 little black 为 51.0%（均为前者胜率）。单档难度仍有差异，CPU 结果不等同于真人胜率；后续重点观察 RajerWei 对 little black。完整前后对比、分难度结果与复测方法见[平衡验证报告](../BALANCE.md)。

## LBB 办公室

![游戏运行时办公室背景](../../assets/stage/office.png)

故事围绕 LBB 的下班后冲突展开。办公室背景中的工位、玻璃隔间与办公设备构成舞台氛围；战斗没有场景伤害机关或可破坏地形。角色之间的距离和场上生成的道具决定交锋节奏。

第一次玩，建议先阅读[操作说明](getting-started.md)，选择简单 CPU，练习站防、蹲防和 `26 + 拳`。
