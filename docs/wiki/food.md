# 食物与召唤

[返回百科首页](README.md) · [RajerWei](rajerwei.md)

食物属于生成它的**玩家槽位**，不是属于某个角色名字。两个 RajerWei 镜像对战时，也各自拥有自己的汉堡和披萨。

## 汉堡

| 属性 | 当前规则 |
| --- | --- |
| 来源 | 地面汉堡，24 + A/C，消耗 50 能量 |
| 生成 | 招式 f24 抛出，飞行 20 帧 |
| 落点 | 施放时前方约 80 逻辑像素，横向限制在 32–608 |
| 拾取等待 | 落地后 30 帧 |
| 存在时间 | 落地后约 360 战斗帧，约 6 秒 |
| 生成者拾取 | 恢复 200，即最大生命的 20%，不超过 1000 |
| 对手拾取 | 扣除 200，可 KO，不受防御或连段衰减影响 |
| 数量限制 | 每名生成者最多一个；旧汉堡存在时不能再次施放 |

20% 指最大生命的 20%，不是当前生命的 20%。生成者满血时不会消耗自己的汉堡；对方即使满血，踩到满足条件的敌方汉堡仍会扣血。

## 披萨

| 属性 | 当前规则 |
| --- | --- |
| 来源 | 肯德基挚友消耗 50 能量，召唤后生成三片，无需额外输入 |
| 生成时机 | 召唤 f28 出现，其实体年龄到 4 帧时生成披萨 |
| 落点 | 招式起始位置附近 −32／0／+32 逻辑像素，受场地限制 |
| 飞行／拾取等待 | 飞行 24 帧，落地再等 12 帧 |
| 存在时间 | 落地后约 240 战斗帧，约 4 秒 |
| 效果 | 每片 +50 生命，三片最多 +150，不能超过 1000 |
| 谁能吃 | 只有生成者；对手不会拾取或触发效果 |
| 再次召唤 | 自己的召唤实体或任一披萨仍存在时不可再次发动 |

披萨会在召唤打击之后产生，并不要求召唤命中。召唤只在启动时锁定落点，不持续追踪对手。

## 共同拾取条件

食物在落地等待期结束后，玩家脚底水平距离其不超过 18 逻辑像素时自动尝试拾取，不需要按键。玩家必须在地面自由状态，生命大于 0，且本帧没有受击或防御接触。

攻击、翻滚、受击、防御硬直、倒地、起身、跳跃及抓取演出期间不能拾取。每次拾取后有 12 帧间隔，因此三片披萨不会在同一帧全部吃完。

双方争同一个汉堡时，距离更近者优先；同一食物同距离时，生成者优先。已有 KO 的战斗帧跳过拾取，不能依靠同帧食物把已归零生命救回来。回合结束后进入新回合时，道具清空。

## 实战用途

汉堡既是补给，也会改变对方可安全走过的位置。披萨是施放者专属补给，但对方仍能通过压制阻止取回。投掷和召唤都花时间，食物也会过期，因此先创造距离，再考虑回血。
