## 最终验收

在冻结数值后，使用未参与调参的种子 2000–2031，分别对原版和最终版各运行 576 场完整对局。每个对位、每档 CPU 为 32 组种子 × 左右换边 = 64 场，先赢两局获胜。下表胜率均为对位中前一角色的整场胜率。

| 对位 | 原版合计 | 最终版合计 | 原版胜率 → 最终版胜率 |
| --- | ---: | ---: | ---: |
| RajerWei : JU GUAI | 89 : 103 | 101 : 91 | 46.4% → 52.6% |
| RajerWei : little black | 53 : 139 | 77 : 115 | 27.6% → 40.1% |
| JU GUAI : little black | 106 : 86 | 98 : 94 | 55.2% → 51.0% |

| 难度 | 对位 | 原版 | 最终版 | 最终版前者胜率 |
| --- | --- | ---: | ---: | ---: |
| 简单 | RajerWei : JU GUAI | 38 : 26 | 32 : 32 | 50.0% |
| 简单 | RajerWei : little black | 14 : 50 | 28 : 36 | 43.8% |
| 简单 | JU GUAI : little black | 28 : 36 | 38 : 26 | 59.4% |
| 普通 | RajerWei : JU GUAI | 42 : 22 | 41 : 23 | 64.1% |
| 普通 | RajerWei : little black | 14 : 50 | 28 : 36 | 43.8% |
| 普通 | JU GUAI : little black | 18 : 46 | 20 : 44 | 31.2% |
| 困难 | RajerWei : JU GUAI | 9 : 55 | 28 : 36 | 43.8% |

九组单档对位中，胜率偏离 50% 的最大幅度由 43.8 降到 18.8 个百分点。最终版 1437 个回合中 48 个超时，整场平局 0 场。

## 测试方法和边界

- 本次共运行 3600 场对位模拟，涵盖原版、仅修复 CPU、三轮候选和两批独立验证；最终数值共运行 1008 场（432 场训练 + 576 场最终验收）。上表只使用最后一批验收数据，未混入训练数据。
- 两个 CPU 使用同一难度和相同输入规则。种子为 `73129 + seed_id * 7919 + 角色在对位中的索引 * 100003`；换边时种子跟随角色。换边用于排除站位偏差，两侧结果相关，不能当作 64 个完全独立样本。
- 原版对照同时保留原版 CPU，因此前后差异包含 AI 输入修复的影响；不是纯数值的因果实验。另跑过 216 场仅修复 CPU 的对照，用于确认不能只靠修复 AI 消除角色倾斜。
- 三档仍是同一种 AI 的不同反应延迟，并未覆盖所有真人打法。尤其普通 CPU 的 JU GUAI 对 little black 仍偏弱；没有为了消掉单档样本差异继续改强弱方向。
- 这是自动化平衡基线，不代表真人竞技胜率已到 50%。后续真人换人换边时，重点记录食物实际回收率、指令投成功率、被防后惩罚和 MAX 转化收益。

专项与回归结果：

- CPU 蹲轻脚输入：三角色、双朝向通过。
- 普通 MAX + 大招 200 总预算、快速 MAX + 大招 300 总预算：三角色、双朝向通过；不足 100 不扣能量或清空 MAX。
- 三角色对全部目标角色、双朝向的投射物蹲防通过。
- 面谈、铁山靠、音爆、露出鸡脚完整被防后，在近身双朝向场景均留出至少 4 个战斗帧的行动差；能否具体惩罚还取决于距离和招式。
- 中场/墙角、双朝向的两类满能量脚本路线通过，累计最大伤害 510，结束后防守者恢复自由状态。路线可能断连，不视为保证真连或所有连段的上限。
- 食物费用、不能叠放、恢复 200、篮球和长裤分别限量通过。
- `tools/check.sh` 全部通过：303 项规则、技能、little black、平衡、VFX、版本门禁、四组回滚和 27 场长跑。
- 32 场网络模拟全部收敛：5% 丢包、±2 tick 抖动、500ms 短时断流。
- 百科 9 页构建、导航、链接、图片与锚点检查通过。

## 复测

```sh
bash tools/check.sh
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/balance.gd -- --tournament 32 2000
/Applications/Godot.app/Contents/MacOS/Godot --headless --path . --script tests/network_chaos.gd
```

比赛结果逐行输出 JSON，含胜场、超时回合、招式使用次数、打击伤害、回血与 MAX 次数。`--tournament` 后两个参数依次是种子数量和起始种子；省略该开关只运行快速专项。
